# Plugin-Gruppen

[Repository-Start](../README.md) · [Plugin-Katalog](../README.md#was-ist-drin) · [Download-Index](../ASSET_INDEX.md)

Thematische Einstiegsknoten für Rechtsgebiete, in denen mehrere Einzelplugins zusammenarbeiten. Die installierbaren Plugins bleiben in ihren eigenen Verzeichnissen; die Gruppen ordnen nur den Einstieg.

| Gruppe | Wofür |
| --- | --- |
| [Fachanwaltschaften](../_FACHANWALTSCHAFTS-PLUGINS/README.md) | Fachbezogene Mandatsführung mit Überblick über die jeweiligen Spezialskills. |
| [Gerichte und Staatsanwaltschaft](../gerichtsplugins/README.md) | Rollenbezogene Vorbereitung von Verfahren, Verfügungen und Entscheidungen. |
| [`insolvenzrecht`](./insolvenzrecht/) | Insolvenz, Sanierung, StaRUG, Fortbestehensprognose, Liquiditätsplanung, Forderungsanmeldung, Insolvenzverwaltung, Verbraucherinsolvenz und Cross-Border-Bankruptcy. |

Jeder Plugin-Link führt zu dessen eigener Anleitung mit Skill-Verzeichnis, Werkstatt, Schnellstart und zugeordneten Akten. Die [fünf vollständigen Register](../README.md#alle-vollständigen-listen-von-a-bis-z) enthalten auch die Plugins außerhalb dieser Gruppen.

English: These directories group related plugins without installing them together. Open a plugin README to choose its package, standalone prompt or practice case.
