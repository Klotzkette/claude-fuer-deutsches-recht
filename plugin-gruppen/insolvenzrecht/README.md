# Insolvenzrecht

Im [Fachbereich Insolvenzrecht](../../Fachbereiche/Insolvenzrecht/README.md) findest du 16 einzeln installierbare Pakete mit Beschreibungen und ZIP-Downloads.

## 1. Zur gemeinsamen Übersicht

Wähle das Paket nach der Aufgabe im Mandat oder Verfahren. Die [Auswahlhilfe](../../insolvenzrecht-plugins/README.md) bietet Einstiege zur Anmeldung und Prüfung von Forderungen, zur Prüfung der Insolvenzgründe, zu Insolvenz- und StaRUG-Plänen, zur Verwaltung und zur gerichtlichen Bearbeitung.
