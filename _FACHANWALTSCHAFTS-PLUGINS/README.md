# Fachanwaltschafts-Plugins: Übersicht

Dieser Ordner ist ein Wegweiser zu 24 Plugins, kein eigenes Plugin und kein installierbares Paket. Die Einträge sind alphabetisch nach Plugin-Slug sortiert. Das Steuerrechts-Plugin heißt im Marketplace `steuerrecht-anwalt-und-berater` und steht deshalb am Ende der Liste.

## Welche Datei wofür?

| Bestandteil | Zweck und Zugang |
| --- | --- |
| Plugin-Verzeichnis und `README.md` | Beschreibung, Einstieg und Links zu den zugehörigen Dateien. Die Plugin-Namen unten öffnen das Verzeichnis. |
| Plugin-ZIP | Installierbares Gesamtpaket mit Skills, Referenzen und Hilfsdateien. Download über die jeweilige Plugin-README oder den [Asset-Index](../ASSET_INDEX.md). |
| `skills/<skill-name>/SKILL.md` | Einzelner Arbeitsablauf innerhalb des Plugins; gegebenenfalls mit weiteren Referenzen. Die Links „Skills“ unten öffnen die vollständige Liste mit Kurzbeschreibungen und direkten Markdown-Downloads. |
| Schnellstart-/Mini-Prompt | Kompakte eigenständige Markdown-Datei für den Einstieg, kein Skill und nicht im Plugin-ZIP enthalten. Download über die [Promptliste](../PROMPTLISTE.md). |
| Werkstatt-Prompt | Ausführliche eigenständige Markdown-Datei für mehrstufige Aufgaben, kein Skill und nicht im Plugin-ZIP enthalten. Download ebenfalls über die [Promptliste](../PROMPTLISTE.md). |
| Testakte | Separate Beispieldokumente zum Erproben; kein Bestandteil der Plugin-Installation. Zugang über die [Testakten-Übersicht](../testakten/README.md). |

README- und Verzeichnislinks dienen der Navigation. Die mit „MD herunterladen“ beschrifteten Prompt-Links führen zur Download-Seite für die Arbeitsdatei. Falls der automatische Download blockiert wird, nutze dort die Download-Schaltfläche.

English: This folder is a guide to 24 plugins, not an installable plugin. Names below open plugin folders; “Skills” opens the complete list with descriptions and individual Markdown downloads. Plugin ZIPs are installable packages. Quick-start and workshop prompts are separate Markdown downloads, not skills or ZIP contents. See the [complete registry](../README.md#alle-vollständigen-listen-von-a-bis-z) and read the [precautions](../README.md#kontrollliste-vor-echtem-mandatsmaterial) before using real case material.
