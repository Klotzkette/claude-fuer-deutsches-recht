# Betriebsvereinbarungen

Das Fachplugin begleitet Arbeitgeber und Betriebsrat von der ersten Projektinformation über Sachverständigenauftrag und Verhandlung bis zur Durchführung und Kontrolle einer Vereinbarung. Die Akte aus Kassel behandelt die Einführung von Microsoft 365 Copilot im Maschinenbau. Sie enthält Eingangsmaterial, spätere Unterlagen und ausfüllbare Vorlagen. Die Originalformate und die Einzel-PDFs stehen als getrennte ZIPs bereit.
