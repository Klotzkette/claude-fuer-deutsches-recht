# IP-Sicherheiten in der Insolvenz – drei Übungsakten

Die Komponente veröffentlicht drei lebensnahe Akten für das Plugin `fachanwalt-urheber-medienrecht`: sicherungsübertragene Markenrechte, eine Steuersoftware-Plattform mit fünf Entwicklerarbeitsverträgen sowie eine Filmproduktion mit getrennten körperlichen Trägern, Lizenzforderungen und Immaterialgüterrechten.

Jede Akte endet beim unterzeichneten Erwerbsvertrag und der angekündigten Verwertung. Die Aufgabe besteht darin, ein Gutachten für den IP-Sicherheitennehmer zu erarbeiten. Eine Lösung ist nicht enthalten.

Je Akte stehen ein Gesamt-PDF, ein ZIP mit nativen Originaldateien und ein ZIP mit jeder Unterlage als Einzel-PDF bereit. Das Originalformat-ZIP enthält bewusst weder das Gesamt-PDF noch eine Gesamtlösung.
