# Was aus den Pull Requests und Issues geworden ist

Stand der Erhebung am 19. November 2026 (MEZ), vor den Änderungen dieser Arbeitsrunde. Das Repository besteht seit dem 18. Mai 2026.

Von den gemergten PRs wurden 636 unter dem Konto Klotzkette und zwei unter anderen Konten eröffnet ([#185](https://github.com/Klotzkette/claude-fuer-deutsches-recht/pull/185), [#208](https://github.com/Klotzkette/claude-fuer-deutsches-recht/pull/208)). Merge und spätere Korrektur desselben Gegenstands zählen als getrennte Vorgänge.

## Wie die Zahlen zustande kommen

GitHub GraphQL lieferte sieben Seiten mit 670 Pull Requests und eine eigene Issue-Liste mit 24 Einträgen. Seitenenden, Gesamtzahlen und eindeutige Nummern wurden abgeglichen. Zusätzlich wurden Kommentare und Abschlussereignisse aller Issues, die 32 geschlossenen PRs ohne Merge sowie die im Repository dokumentierten Einzelentscheidungen ausgewertet. Issue #406 lieferte beim separaten GitHub-Abruf HTTP 404. Sein Betreff ist in der Einzeltabelle als rekonstruierter Gegenstand gekennzeichnet.

Die Spalte „Eröffnet von“ bezeichnet das GitHub-Konto. Die Themenzeile gibt den dokumentierten Arbeitsschwerpunkt wieder. Der Merge-Status belegt die damalige Integration. Ob später ein anderer Inhalt an seine Stelle trat, ist jeweils am aktuellen Fachtext zu prüfen. Bei 635 der 638 gemergten PRs ist der von GitHub gemeldete Merge-Commit direkt im vollständigen Verlauf des geprüften main-Stands enthalten. Bei #1, #2 und #10 weist GitHub einen historischen Merge aus, dessen genauer Commit dort nicht vorkommt.
