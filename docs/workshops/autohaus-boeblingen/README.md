# Kursleitung zum Autohaus Schönbuchring

Die [Fallseite des Autohauses](../../../testakten/autohaus-boeblingen/README.md) führt zu den Arbeitsunterlagen. Beginnen Sie im Kurs mit der E-Mail der Geschäftsführerin vom Freitagabend und der unbearbeiteten Grundakte. Lassen Sie die Teilnehmenden festhalten, welche Zeile im Wochenplan den Auftrag entscheidet und welche Unterlage zur Freigabe fehlt. Geben Sie anschließend die sechs Stücke aus dem Ordner `Nachlieferung` aus. Erst nach der eigenen Auswertung eignen sich die folgenden Importe für die Kontrolle.

| Kontrollmaterial | Verwendung |
| --- | --- |
| [Ausgefüllte Datei für den Liquiditätsplaner](kontrolle-liquiditaetsplaner.json) | Die JSON-Datei speichern. Im HTML-Rechenblatt des Liquiditätsplaners „Stand laden“ auswählen. Die ersten drei Wochen mit dem operativen 13-Wochen-Plan P01 abgleichen. |
| [Ausgefüllte Datei für den Insolvenzreifeprüfer](kontrolle-insolvenzreife.json) | In der lokalen Prüfoberfläche die JSON-Datei öffnen und berechnen. Sie enthält die belegbezogenen Einzelansätze für beide Eröffnungsgründe. |
| [Nachbesprechung mit Einzelnachweisen](auswertung.md) | Rechenweg, Einwände gegen die Bewertung und zeitliche Grenzen des Befunds besprechen. |

Die Quellen für die Erzeugung der Geschäftsdokumente und Importe stehen in diesem Ordner. Die freigegebenen Teilnehmerdokumente liegen im zugehörigen Aktenordner.
