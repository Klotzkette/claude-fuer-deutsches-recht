# Drei Insolvenzreifeakten mit zweitem Belegeingang

Jede Akte enthält die vollständigen Originalunterlagen. Beginnen Sie mit dem Ordner `Grundakte` und halten Sie Ihren Befund zu jedem untersuchten Tag fest. Öffnen Sie dann `Nachlieferung`. Dort liegen die Anfrage der Insolvenzverwaltung, die Antwort mit zwei Anlagen und beide Anlagen als einzelne Arbeitsdateien. Aktualisieren Sie den betroffenen Ansatz und halten Sie fest, ob die Antwort eine frühere Annahme bestätigt, widerlegt oder eine zweite vertretbare Bewertung begründet.
