# Vergabe-Streitdashboard Bieter

| Bereich | Inhalt |
|---|---|
| Rolle & Ziel | Bieter, Bewerber, Beigeladener oder Kanzlei; wirtschaftliches Ziel; Prozessziel; gewünschter Output |
| Rechtsweg | Oberschwelle, Unterschwelle, Sektoren, Konzession, Verteidigung/Sicherheit, Fördermittel; zuständige Vergabekammer oder Gericht |
| Fristenampel | Angebotsfrist, Rügefrist, § 134 GWB, Nichtabhilfe plus 15 Kalendertage, Zuschlagssperre, OLG-Beschwerde, § 135 GWB |
| Dokumente | Bekanntmachung, Vergabeunterlagen, LV/GAEB/XML/Excel/PDF, Fragen/Antworten, Angebot, Wertung, Informationsschreiben, Portalprotokolle |
| Angriffe | Tatsache, Norm, Beleg, Kausalität, Zuschlagschance, begehrte Abhilfe, Beweisangebot |
| Verteidigung der Gegenseite | Dokumentationsbeleg, Ermessen/Wertungsspielraum, Gleichbehandlung, Transparenz, fehlende Kausalität, Präklusion |
| VK/OLG | Antragsbefugnis, Rügeobliegenheit, Akteneinsicht, Beiladung, Eilantrag, Vergleichsfenster, Beschwerdefrist, Kostenrisiko |
| Nächste Aktion | Bieterfrage, Rüge, Nachprüfungsantrag, Eilantrag, Vergleichsvorschlag, OLG-Beschwerde, Schadensersatzprüfung |

## Startbildschirm

Nutze bei Akten-Upload oder unklarem Auftrag zuerst `startbildschirm-applet-dashboard.md`. Stelle höchstens fünf Rückfragen: Was liegt vor, welche Rolle, welcher Verfahrensstand, welches Ziel, welcher Output.

## Pflicht-Applets

| Applet | Mindestinhalt |
|---|---|
| Fristenampel | Frist, Startpunkt, Ablauf, Beleg, Risiko, Sofortmaßnahme |
| Dokumentenmatrix | Dokument, Format, Version, Quelle, Lücke, nächster Schritt |
| Belegmatrix | Behauptung, Belegstelle, Datei, Seite/Position, Gegnerargument, Replik |
| Angriff/Verteidigung | Angriffspunkt, Norm, Kausalität, Gegenargument, Abhilfe, Kostenrisiko |
| Wertungsmatrix | Kriterium, Gewicht, Wertung, Fehler, Zuschlagschance, neue Wertung |
| Upload-/Formatexport | Zielformat, Datei, Hash, Signatur, Portalnachweis, Freigabe |
