# Vergabe-Streitdashboard Vergabestelle

| Bereich | Inhalt |
|---|---|
| Rolle & Ziel | Vergabestelle, Fachbereich, Justiziariat, Beigeladener oder Kanzlei; Beschaffungsziel; Verteidigungsziel; gewünschter Output |
| Rechtsweg | Oberschwelle, Unterschwelle, Sektoren, Konzession, Verteidigung/Sicherheit, Fördermittel; zuständige Vergabekammer oder Gericht |
| Fristenampel | Angebotsfrist, Bieterfragen, Rügen, § 134 GWB, Nichtabhilfe plus 15 Kalendertage, Zuschlagssperre, OLG-Beschwerde, § 135 GWB |
| Vergabeakte | Bekanntmachung, Vergabeunterlagen, LV/GAEB/XML/Excel/PDF, Fragen/Antworten, Angebote, Wertung, Informationsschreiben, Portalprotokolle |
| Angriff des Bieters | Rügepunkt, Tatsache, Norm, Beleg, behauptete Kausalität, begehrte Abhilfe, Fristlage |
| Verteidigung | Dokumentationsbeleg, Ermessen/Wertungsspielraum, Gleichbehandlung, Transparenz, fehlende Kausalität, Präklusion, Heilungsoption |
| VK/OLG | Aktenvorlage, Akteneinsicht/Schwärzung, Beiladung, Eilantrag, Vergleichsfenster, Beschwerdefrist, Kostenrisiko |
| Nächste Aktion | Abhilfe, Nichtabhilfe, Berichtigung, Fristverlängerung, Stellungnahme VK, Vergleichsvorschlag, Beschwerdeerwiderung, Aufhebung |

## Startbildschirm

Nutze bei Akten-Upload, Rüge oder unklarem Auftrag zuerst `startbildschirm-applet-dashboard.md`. Stelle höchstens fünf Rückfragen: Was liegt vor, welche Rolle, welcher Verfahrensstand, welches Ziel, welcher Output.

## Pflicht-Applets

| Applet | Mindestinhalt |
|---|---|
| Fristenampel | Frist, Startpunkt, Ablauf, Beleg, Risiko, Sofortmaßnahme |
| Dokumentenmatrix | Dokument, Format, Version, Quelle, Lücke, Aktenstelle |
| Belegmatrix | Entscheidung, Aktenstelle, Datei, Seite/Position, Begründung, Nachweiswert |
| Angriff/Verteidigung | Rügepunkt, Norm, Aktenbeleg, Gegenargument, Heilung, Kostenrisiko |
| Wertungsmatrix | Kriterium, Gewicht, Wertung, Dokumentation, Fehlerverdacht, Reparaturpfad |
| Upload-/Formatexport | Zielformat, Portal, Feldliste, Datei, Hash, Freigabe, Nachweis |
