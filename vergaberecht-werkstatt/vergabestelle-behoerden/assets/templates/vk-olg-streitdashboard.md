# VK-OLG-Streitdashboard Vergabestelle

## Kurz-Cockpit

| Feld | Inhalt |
|---|---|
| Kurzbild | Verfahren, Auftraggeber, Leistung, Wert, Fristen, aktueller Stand |
| Ziel | Vergabeverfahren verteidigen, rechtmäßige Abhilfe leisten, Zuschlag sichern, Interimsbedarf decken, Schadensersatzrisiko begrenzen |
| Zulässigkeit | EU-Schwelle, zuständige VK, Antragsbefugnis, Rügeobliegenheit, Frist nach Nichtabhilfe, Rechtsschutzinteresse |
| Begründetheit | Rügepunkt, Aktenstelle, Wertungsspielraum, Gleichbehandlung, Transparenz, Kausalität, mögliche Heilung |
| Eilbedarf | § 169 GWB, Zuschlagssperre, Beschleunigungsinteresse, Versorgungssicherheit, Interimsvergabe |
| Akteneinsicht | Aktenverzeichnis, Geheimnisschutz, Schwärzung, getrennte Geheimnisakte, Anhörung betroffener Bieter |
| Beigeladene | Zuschlagsprätendent, Antragsteller, Erwerber nach Insolvenz, Nachunternehmer, Interessenlage |
| Vergleich | Abhilfe ohne Rechtsverlust, neue Wertung, Fristverlängerung, Unterlagenkorrektur, Kostenregelung, Gremienfreigabe |
| OLG-Reserve | Verfahrensbeginn, § 187 Abs. 2 GWB, anwendbare Fassung der §§ 172 und 173 GWB, VK-Beschluss, Zwei-Wochen-Notfrist, Aktenauszug, Kostenrisiko |
| Nächster Schritt | Verantwortlicher, Frist, Entwurfsformat, Anlagen, Freigabe |

## Streitfall-Applets

| Applet | Pflichtfelder | Ergebnis |
|---|---|---|
| Rüge | Eingang, Rügepunkt, Kenntnistag, Norm, Aktenstelle, Abhilfeoption, Antwortfrist | Rügeerwiderung oder Abhilfevermerk |
| Nachprüfungsantrag | Zulässigkeit, Antragsbefugnis, Präklusion, Sachverhalt, Aktenbeleg, Kausalität, Anträge | VK-Stellungnahme |
| Zuschlagssperre | Stillhaltefrist, Beschaffungsdruck, Interimsbedarf, Interessenabwägung, Projektfolge | Eil-Erwiderung nach § 169 GWB |
| Akteneinsicht | Aktenverzeichnis, Geschäftsgeheimnisse, Schwärzung, Geheimnisakte, Anhörung betroffener Bieter | Schwärzungsmatrix und VK-Schreiben |
| VK-Termin | streitige Punkte, Aktenbelege, Behördenlinie, Vergleichsfenster, Sprecher, Beschlussrisiko | Terminsbriefing |
| OLG-Beschwerde | VK-Beschluss, Beschwerdefrist, § 173-Ausgang, Verteidigungslinie, § 176-Bedarf, Gremienfreigabe | Beschwerde/Erwiderung und Zuschlagswirkungs-Memo |
| Vergleich | zulässige Abhilfe, neue Wertung/Frist, Kosten, Projektfolge, Freigabe | Vergleichsvorschlag |
| Kostenrisiko | Streitwert, Gebühren, Verzögerung, Interimsbeschaffung, Haushaltsfolge | Behördenvermerk |
