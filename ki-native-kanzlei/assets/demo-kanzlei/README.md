# Demo-Kanzleiordner

Fiktive Mandatsläufe zum Ausprobieren des Cockpits. Aufruf im Pluginordner:

```bash
python3 scripts/mandatslauf.py cockpit --kanzlei assets/demo-kanzlei --format md
```

M-26-101 hat ein offenes Fristgate, M-26-102 eine wartende Rechnungsfreigabe, M-26-103 eine offene Frage zur Mandantenrolle. Alle Angaben sind fiktiv.
