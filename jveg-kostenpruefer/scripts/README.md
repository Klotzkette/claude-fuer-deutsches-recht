# Scripts

[Plugin-README](../README.md) · [Plugin-Dateien](../) · [Repository-Start](../../README.md)

`jveg_zeugenentschaedigung.py` ist ein kleiner Plausibilitätsrechner für Zeugenentschädigung. Er ist bewusst parametergetrieben, damit gerichtliche Obergrenzen, Belegstatus und Auslandsfälle nicht verdeckt fest verdrahtet werden.

Der Rechner wird aus dem Repository-Wurzelverzeichnis mit `python3 jveg-kostenpruefer/scripts/jveg_zeugenentschaedigung.py` gestartet. Vor einer Verwendung sind die Eingabewerte, der aktuelle Rechtsstand und die Belege des konkreten Kostenfalls zu kontrollieren.
