## 1. Öffentliche Übersicht

Die [veröffentlichte Fachübersicht](https://klotzkette.github.io/claude-fuer-deutsches-recht/) bietet einen visuellen Einstieg in die Fachanwalts-Plugins. Sie ist eine Auswahl; der vollständige Plugin-Katalog steht in der Haupt-README.

| Quelldatei | Zweck |
| --- | --- |
| [download.html](./download.html) | Downloadseite für Markdown-Arbeitsdateien; die Verzeichnisse übergeben den gewünschten Dateipfad. |
| [index.html](./index.html) | Quellseite der veröffentlichten Fachübersicht. |

## 2. Markdown als Datei herunterladen

Wähle in einer Plugin-README oder im Download-Index „MD herunterladen“. Die veröffentlichte Downloadseite lädt die Datei und startet den Speichervorgang. Falls der Browser diesen blockiert, steht auf der Seite ein eigener Downloadknopf bereit; JavaScript muss aktiviert sein. Ein direkt in GitHub geöffnetes HTML-Quelldokument führt diesen Vorgang nicht aus.

Die Bereitstellung der Übersichtsseite und der Markdown-Dateien erfolgt über den [Pages-Ablauf](../.github/workflows/pages.yml). Die ZIP-Pakete werden getrennt im [Release](https://github.com/Klotzkette/claude-fuer-deutsches-recht/releases/latest) veröffentlicht.

## 3. English

Use the published site for the visual specialist overview and the repository indexes for the complete collection. “Download MD” links open a download page with automatic saving and a manual fallback button. JavaScript is required. Opening an HTML source file on GitHub does not run the download page.
