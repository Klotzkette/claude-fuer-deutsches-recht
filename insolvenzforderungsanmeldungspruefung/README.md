# Insolvenzforderungsanmeldungsprüfung

Der [Insolvenzforderungen-Checker](../insolvenzforderungen-checker/README.md) bearbeitet Forderungsanmeldungen im eröffneten Verfahren. Für Gläubiger entsteht aus Vertrag, Leistungsbeleg und Saldenabgleich ein adressierter Anmeldungsentwurf. Die Insolvenzverwaltung erhält für jeden Eingang einen begründeten Prüfvorschlag, eine Tabellenzeile und den erforderlichen Gläubigerbrief.

Für die eigene Anmeldung führt der [Gläubigerskill](https://klotzkette.github.io/claude-fuer-deutsches-recht/download.html?path=insolvenzforderungen-checker/skills/forderung-zur-insolvenztabelle-anmelden/SKILL.md) von der Anspruchsgrundlage bis zum Anlagenverzeichnis. Für die Prüfung eingegangener Anmeldungen öffnen Sie den [Hauptskill](https://klotzkette.github.io/claude-fuer-deutsches-recht/download.html?path=insolvenzforderungen-checker/skills/forderungen-pruefen-und-tabelle-vorbereiten/SKILL.md). Der [Leitfaden für Anmeldung, Prüfung und Nachlauf](../insolvenzforderungen-checker/references/anmeldung-pruefung-nachlauf.md) enthält Arbeitsregister, Schreiben und Prüfschritte für den Fall eines Widerspruchs.
