Beamtenrechtliche Akte um eine auffällige Planstellenrotation in einem Landesamt: Die Behördenleitung möchte eine bestimmte Person auf eine A15-Stelle bringen, verschiebt zuvor aber stärkere Konkurrentinnen und Konkurrenten auf andere Funktionen. Der Fall prüft die Grenze zwischen Organisationsgewalt und Umgehung der Bestenauslese.
