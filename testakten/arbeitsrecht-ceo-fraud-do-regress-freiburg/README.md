# Fünf Freigaben · Arbeitnehmerhaftung und D&O in Freiburg

Die Dreisamtal Sensorik GmbH verlangt nach fünf betrügerisch veranlassten Überweisungen 5,5 Millionen Euro von ihrer Treasury-Leiterin. Vor dem Arbeitsgericht Freiburg geht es um Zahlungsfreigaben, einen frühen internen Warnhinweis und die persönliche Haftung. Die Deckungsakte einer arbeitgeberfinanzierten D&O-Versicherung enthält eine vorläufige Kostenübernahme und ein begrenztes Jahresaggregat.

Die Akte verwendet fiktive Beteiligte und reservierte Kontaktadressen. Sie enthält die Zahlungsklage, die Klageerwiderung, das Güteprotokoll und die gerichtliche Verfügung zur Vorbereitung des Kammertermins.
