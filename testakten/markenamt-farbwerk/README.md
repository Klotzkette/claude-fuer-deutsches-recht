## 1.2. Vorgang

Eine inhabergeführte Baumarktkette verteidigt eine abstrakte Farbmarke. Zwei Befragungen verwenden unterschiedliche Grundgesamtheiten und Stimuli. Parallel sind Umfirmierung, Registeranschrift, Verlängerung und ein privates Gebührenangebot zu bearbeiten.

Stand: 01.10.2026. Mandat: Farbwerk Heimbedarf GmbH.

Passendes Plugin: [`markenamt-assistent`](../../markenamt-assistent/README.md).

## 1.3. Arbeitsauftrag

Entwickeln Sie die Verteidigung gegen den Nichtigkeitsantrag, prüfen Sie den Aussagewert der Befragungen und bereiten Sie die erforderlichen Registeränderungen vor. Berechnen Sie keine sichere Frist ohne Zustellnachweis. Treffen Sie keine eigenmächtige Entscheidung über Aufgabe oder Einschränkung der Marke.
