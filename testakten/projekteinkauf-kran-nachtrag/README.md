# Der letzte Hub war um 16:42 Uhr

Eine technische Anweisung zum Stellflächenwechsel, ein vor Ort gebliebener Kran und eine offene Reservierung führen zu drei Nachtragspositionen. Der Einkauf klärt Beauftragung, Leistungszeit und doppelt berechnete Warteblöcke.

Die Akte gehört zum fiktiven Bildungscampus Leineaue. Die Kontaktadressen verwenden reservierte Beispieldomains.
