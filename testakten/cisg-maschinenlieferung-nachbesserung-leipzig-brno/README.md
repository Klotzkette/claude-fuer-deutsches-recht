# 1. Abfüllmaschine Brno Leipzig

Eine neue Abfüllmaschine soll zwei Flaschenformate im Zweischichtbetrieb verarbeiten. Nach Werkstest und Lieferung folgen wiederholte Störungen, zwei Serviceeinsätze und ein gemeinsamer Dauerlauf. Ein alternatives Maschinenangebot liegt vor; der laufende Liefervertrag ist noch nicht aufgehoben.
