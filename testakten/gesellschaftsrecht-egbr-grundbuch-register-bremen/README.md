# Zwei Blätter, ein falscher Name · Kontorwerft eGbR

Die Kontorwerft eGbR verkauft zwei Grundstücke in Bremen-Walle. Auf einem Grundbuchblatt steht seit einer fehlerhaften Namensumschreibung die falsche Gesellschaft. Im Gesellschaftsregister fehlt zugleich die Änderung der Vertretung. Der Erwerb und ein späteres Berichtigungsverlangen hängen von den beiden Registerständen und von den belegbaren Kenntniszeitpunkten ab.

Die Akte verbindet historische und aktuelle Registerunterlagen, den notariellen Kaufvertrag mit zwei Auflassungen, Einreichungsprotokolle, E-Mails und das anwaltliche Berichtigungsverlangen. Sie verwendet fiktive Personen und reservierte Kontaktadressen.
