# 1. Sensorenlieferung Turin Ulm

120 Präzisionssensoren werden in Turin an einen vom Käufer beauftragten Straßenfrachtführer verladen. Ein Stoßereignis, unterschiedliche Verpackungsstärken und ein nach der Entladung ergänzter Vorbehalt stehen neben Prüfberichten, Teilzahlungen und einer noch offenen Versicherungsbearbeitung.
