# Das PDF sagt 19 Prozent, die XML sagt null – Vorsteuer aus der E-Rechnung

Umsatzsteuer 2026 · Zwei Fassungen einer Eingangsrechnung · Voranmeldungszeitraum und Klageentscheidung. Stand der Sammlung 4. November 2026. Personenrollen, Mandate und Vorgänge sind für diesen Fall fiktiv. Die Übungsunterlagen enthalten keine echten Steuerdaten.

## 1 Arbeitsauftrag

Ermitteln Sie aus Rechnung, XML-Auslesung, Übermittlungsprotokollen und Verfahrensakte, in welchem Quartal die GmbH 912 Euro Vorsteuer beanspruchen kann. Benennen Sie die belastbare Erklärungskorrektur und entscheiden Sie, ob sich eine Klage für das andere Quartal lohnt.
