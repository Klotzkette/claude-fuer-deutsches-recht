Ein Berliner Universitätslabor soll zugunsten gemeinsamer Nutzung umziehen. Professor Linden unterstützt die Idee, benötigt für seine Klimasensoren jedoch ununterbrochene Messfenster, ausreichende Arbeitsflächen und Klarheit über zweckgebundene Mittel.

Stand: 30.09.2026. Mandat: Prof. Dr. Tarek Linden.
