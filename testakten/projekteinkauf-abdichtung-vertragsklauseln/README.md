# Dachabdichtung mit zwei Preiswegen und klaren Schnittstellen

Die Bauleitung benötigt eine abschnittsweise Dachabdichtung. Der erste Vertragsentwurf und die Bedingungen des Nachunternehmers regeln Preis, Abnahme und Schlusszahlung gegensätzlich. Ein neuer Planstand, ein geänderter Materialpreis und ein zweites Vertragsangebot eröffnen zwei belegte Verhandlungsoptionen.

Die Akte gehört zum fiktiven Bildungscampus Leineaue. Die Kontaktadressen verwenden reservierte Beispieldomains.

Öffnen Sie zuerst die Dateien der ersten Stufe. Geben Sie später die jeweils nächste Gruppe hinzu und führen Sie den Entwurf fort.
