# C frei, aber wer hat bestellt?

Ein Innenausbauauftrag wird aus 17 nativen E-Mails, Zeichnungsständen, Angeboten und Baustellenberichten rekonstruiert. Eine verkürzte Freigabenotiz, ein fremdes Anweisungsfeld und ein später gesperrter Teilbereich stellen die bisherige Einkaufsempfehlung auf die Probe.

Die Akte gehört zum fiktiven Bildungscampus Leineaue. Die Kontaktadressen verwenden reservierte Beispieldomains.
