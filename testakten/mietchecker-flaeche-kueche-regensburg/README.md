## 1.4. Arbeitsfassungen

Zwölf getrennte Unterlagen in DOCX, EML, CSV und TXT. Das Gesamt-PDF enthält dieselben Vorgänge; das Einzel-PDF-ZIP jedes Dokument separat. Das Originalformat-ZIP enthält keine Markdown-Aktenstücke. Beide ZIPs sind flach. Für eine Bearbeitung nur eine Fassung verwenden, damit Unterlagen nicht doppelt gezählt werden.

English: Twelve separate documents concerning residential rent in Regensburg, using the official local 2026 rent index. The case can be approached from either tenant or landlord perspective without a model answer. Combined PDF, individual-PDF ZIP and original-format ZIP contain the same material.
