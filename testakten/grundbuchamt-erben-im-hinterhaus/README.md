## 1.2. Vorgang

Berta Bregenzer hinterlässt ein Berliner Mietshaus und ein notarielles Testament, das ihre Kinder ohne Namen bezeichnet. Drei Geschwister möchten das Grundbuch berichtigen. Während Urkunden zusammengesucht werden, tauchen eine alte Karte aus Prag und eine Vollmacht aus dem Jahr 2011 auf.

Stand: 01.10.2026. Mandat: Nela Lieselotte Bregenzer.

Passendes Plugin: [`grundbuchamt-assistent`](../../grundbuchamt-assistent/README.md).

## 1.3. Arbeitsauftrag

Bearbeiten Sie die Zwischenverfügung anhand der vorhandenen Unterlagen. Formulieren Sie die erforderliche Antwort und die gezielten Nachforderungen. Trennen Sie die Berichtigung nach Erbfolge von der zusätzlich diskutierten Finanzierung; machen Sie aus Familienerinnerungen keine gesicherten Personenstandstatsachen.
