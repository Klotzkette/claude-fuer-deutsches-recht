## Kurzbild

Die Lipsia Speichertechnik AG erhält eine Kommissionsentscheidung zur Rückforderung einer kommunalen Garantie. Zwischen Zustellung, städtischer Anhörung, drohender Liquiditätsbelastung und Klage beim Gericht der Europäischen Union entstehen Frist-, Vollmachts-, Vertraulichkeits- und Anlagenprobleme. Eine technisch erfolgreiche e-Curia-Einreichung wird später formal beanstandet.
