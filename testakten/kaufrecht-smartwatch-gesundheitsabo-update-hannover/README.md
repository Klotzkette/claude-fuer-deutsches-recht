## Überblick

Käuferin erwirbt eine Smartwatch mit EKG-Funktion, Sturzerkennung und Gesundheitsabo. Nach einem Update fehlen Funktionen, Messwerte driften, der Händler behauptet, es gehe nur um eine App-Leistung.
