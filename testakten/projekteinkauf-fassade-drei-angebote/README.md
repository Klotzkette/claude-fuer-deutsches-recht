# Drei Fassadenangebote auf einer Leistungsbasis

Nele Thomsen vergleicht drei Fassadenangebote für den Bildungscampus Leineaue in Hannover. Unterschiedliche Laibungseinheiten, ein Skonto und ausgeschlossene Leistungen verfälschen den ersten Preisvergleich. Nachträge klären Fracht, Bühne und Unterkonstruktion.

Die Akte gehört zum fiktiven Bildungscampus Leineaue. Die Kontaktadressen verwenden reservierte Beispieldomains.
