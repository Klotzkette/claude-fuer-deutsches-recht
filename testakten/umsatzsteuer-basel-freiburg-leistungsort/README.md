# Basel bucht, Freiburg liefert

Umsatzsteuer 2025 · Zwei Arbeitspakete und ein umstrittenes Verbindungsbüro. Stand der Sammlung 4. November 2026. Personenrollen, Mandate und Vorgänge sind für diesen Fall fiktiv. Die Übungsunterlagen enthalten keine echten Steuerdaten.

## 1 Arbeitsauftrag

Rekonstruieren Sie aus Voranmeldungen, Jahreserklärung, Vertrags- und Nutzungsunterlagen, welche Leistung an welchen Empfängerstandort erbracht wurde. Prüfen Sie den Bescheid in Gestalt der Einspruchsentscheidung und arbeiten Sie die gerichtliche Begründung einschließlich Beweisangeboten und betragsmäßig nachvollziehbarem Antrag aus.
