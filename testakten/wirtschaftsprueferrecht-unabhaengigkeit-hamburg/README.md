## Kurzbild

Eine Wirtschaftsprüfungspraxis prüft den Abschluss eines kapitalmarktorientierten Energieanlagenbauers. Parallel erbringt das Netzwerk Steuer- und Systemleistungen. Eine familiäre Beziehung im Prüfungsteam, verspätet entzogene Zugriffsrechte, unklare Ausschussfreigaben und Änderungen nach dem Bestätigungsvermerk geraten in den Fokus einer APAS-Inspektion.
