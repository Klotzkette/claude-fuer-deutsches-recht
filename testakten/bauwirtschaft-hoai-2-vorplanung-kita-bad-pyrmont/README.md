## 1.5. Reproduktion und Prüfung

Builder: `scripts/build-bauwirtschaft-hoai-1-3-akten.py`, `scripts/build-bauwirtschaft-hoai-1-3-tabellen.mjs` und `scripts/build-bauwirtschaft-hoai-1-3-pakete.py`, jeweils mit `--phase 2`. Die drei Inhalte wurden individuell verfasst; gemeinsam genutzt werden nur Formatierung, Rendering und Export. Artifact Tool erstellt die Formeln, native Office-Neuberechnung prüft deren Ergebnisse. Der zentrale Gesamt-PDF-Builder wird unverändert nur auf die eigene Zielakte angewendet.

Laufzeitkonfiguration: `AKTEN_NODE_MODULES`, `SOFFICE`, `DOCX_RENDERER`, `DOCX_PYTHON`, `HOAI_1_3_ASSETS`. Der Offline-Standardlauf von `scripts/test-bauwirtschaft-hoai-1-3.py` benötigt keine temporären Vorprodukte. `--assets DIR` prüft zusätzliche Exportdateien, `--native` verwendet Wegwerfkopien für Eingabeänderungen. Technische Prüfungen und offene menschliche Rubrikfragen werden getrennt; kein Live-Modelltest wird behauptet.
